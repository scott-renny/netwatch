# Contributing

This is a public engineering portfolio maintained by Scott Renny.

1. Open an issue describing the proposed correction or improvement.
2. Do not publish credentials, private addresses, device identifiers, recovery material, or personal information.
3. Use a short-lived branch and a focused pull request.
4. Document validation and any operational impact.
5. Keep examples sanitized and use documentation address ranges where network values are required.

By contributing, you agree that original contributions may be distributed under this repository's license.
